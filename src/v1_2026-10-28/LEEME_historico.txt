original working session (cd /tmp/..., /mnt/user-data/..., ../c7_templates) and call the first motor C binary
(motorc_new), so they do not run as delivered.  The large cells were finally run with the laboratory packages
lab/fase2b (motor C and motor B for C7) and lab/fase2c (C11), which use the optimised motors of src/.
