AUTOTEST for the laboratory package (inputs in this folder; expected values computed on Linux and checked with the
Windows binaries of ../bin under wine 9.0).  Every test writes only its own outputs.  Times: Linux, 1 core.

All motorc outputs are written in binary mode (LF), so the Windows hashes equal the Linux ones.
motora.exe writes its output in text mode (CRLF on Windows): two hashes are given (Linux LF / Windows CRLF);
stripping the '\r' from the Windows file gives exactly the Linux file.
